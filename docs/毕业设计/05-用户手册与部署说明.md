# 面镜 MockMirror —— AI 模拟面试与能力提升软件
## 用户手册与部署说明

| 项目 | 内容 |
|------|------|
| 文档版本 | V1.0 |
| 适用对象 | 使用者（学生 / 教师）、部署与运维人员 |

---

## 1 快速开始

### 1.1 Windows

1. 安装 [Node.js 18+](https://nodejs.org/)（安装向导全部默认下一步）；
2. 获取项目：`git clone` 或直接下载压缩包解压；
3. **双击 `启动面试.bat`**；
4. 首次启动会自动下载语音识别运行时与模型（约 192MB，视网络 1~5 分钟），完成后浏览器自动打开 `http://localhost:3000`。

### 1.2 macOS / Linux

```bash
git clone <仓库地址>
cd agent-collab
./start.sh
```

### 1.3 跳过语音模型下载（可选）

若网络受限或仅需快速体验，可使用：

```bash
npm run setup:skip      # 或：node scripts/setup-asr.js --skip
```

此时语音识别自动回退到浏览器内置识别（Chrome / Edge 可用），面试流程不受影响。

## 2 配置大模型（AI 面试官）

> 未配置大模型时，系统会提示"AI 尚未配置"，此时可使用离线演示模式完成流程，但追问深度有限。

1. 打开网页右上角 **AI 设置**；
2. 选择引擎 `llm`，填写：
   - 接口地址：如 `https://api.deepseek.com/v1`
   - 模型名：如 `deepseek-chat`
   - API Key：服务商提供的密钥
3. 保存后页面提示"AI 已就绪"即可开始面试。

**密钥安全说明**：配置保存在 `data/config.local.json`，该文件与 `data/backups/` 均已纳入 `.gitignore`，不会被提交到版本库。

可选引擎：

| 引擎 | 说明 |
|------|------|
| offline | 规则面试官，无需任何外部服务 |
| llm | OpenAI 接口兼容服务（DeepSeek / 通义 / 智谱等均可） |
| python | 转发到本地 Python Agent 服务（默认 127.0.0.1:8000） |

## 3 使用流程

### 3.1 首页

| 区域 | 操作 |
|------|------|
| 左栏 | 选择岗位（Java 后端 / Python 算法 / Web 前端），可粘贴 JD 定制题目 |
| 中栏 | 查看历史面试与能力成长曲线 |
| 右栏 | 押题卡：预览该岗位高频题与回答思路 |

### 3.2 设备与网络检测

点击"开始面试"后弹出检测窗：

- 列出全部麦克风，可切换选择（选择会被记住）；
- 摄像头可选开启，用于临场行为分析（不上传）；
- 检测通过后进入面试间。

### 3.3 面试中

| 操作 | 方式 |
|------|------|
| 作答 | 直接开口说，无需打字 |
| 说完提交 | 停顿约 0.8 秒自动提交，或说"就这些""不会"等结束词立即提交 |
| 打断面试官 | 按 **空格键** 或点击"打断"按钮 |
| 切换麦克风 | 底部控制条切换，会中热切换 |
| 查看 Agent 思考 | 右侧「🧠 Agent 工作台」标签 |
| 结束面试 | 底部"结束面试"按钮 |

> 界面不展示中间识别文本，避免边说边看稿影响真实发挥；识别结果在提交后进入评估。

### 3.4 报告页

| 区块 | 内容 |
|------|------|
| 总分与维度 | 多维度得分与评价 |
| 亮点与短板 | 抽取式结论 |
| 评估官逐题复核 | 每道题"该怎么答" |
| 陪练官计划 | 一周安排 + 针对性练习题 |
| 全程回放 | 逐题题目、原话、追问、指标 |

## 4 管理后台

1. 访问首页底部"管理中心"，输入管理口令登录；
2. 可查看学员列表、面试统计、审计日志；
3. 支持题库导入与删除、数据导出。

> 管理口令以加盐哈希形式存储；请部署后及时修改默认口令。

## 5 MCP 接入（供开发者 / 第三方 AI 工具）

在支持 MCP 的客户端（如 Claude Desktop、Cursor）配置：

```json
{
  "mcpServers": {
    "mockmirror": {
      "command": "node",
      "args": ["<项目绝对路径>/mcp/mockmirror-mcp.js"]
    }
  }
}
```

配置完成后，可直接使用自然语言让外部 AI 主持面试，例如：

> "用 MockMirror 给我面一场 Java 后端，6 道题"

外部 AI 会依次调用 `list_positions → start_interview → submit_answer × N → finish_interview`，并返回评估报告。

可用能力：9 个工具 / 3 类资源 / 2 个提示词模板（详见《02-概要设计说明书》4.3 节）。

## 6 常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| 浏览器提示 `network` 语音错误 | Chrome 内置识别依赖境外服务，国内常被阻断 | 本项目默认使用本地识别引擎；若本地引擎未安装，执行 `npm run setup` 安装 |
| 完全听不到我说话 | 麦克风权限被拒，或选错了设备 | 点击地址栏权限图标重新授权；在检测弹窗或底部控制条切换设备 |
| 说一句被切成两句 | 句间停顿较长触发端点检测 | 正常现象；可连续表达减少停顿，或用空格键手动提交 |
| 提示"端口 3000 已被占用" | 服务已在运行 | 直接访问 http://localhost:3000；若需重启，先关闭占用进程 |
| 双击 .bat 一闪而过 | 未安装 Node.js 或版本过低 | 安装 Node.js 18+ 后重试 |
| .bat 报"'.' 不是内部或外部命令" | 脚本编码问题 | 本项目脚本已统一为纯 ASCII；若自行修改请保持英文 |
| 没有中文女声 | 系统未安装中文语音包 | 双击 `安装中文语音包.bat`（需管理员权限）；或接受系统默认音色 |
| 面试官回答很机械 | 未配置大模型，运行在离线规则模式 | 在 AI 设置中配置大模型 |
| 面试中途卡住 | 大模型超时或网络抖动 | 系统会自动重试；仍失败则降级为离线面试官继续完成面试 |

## 7 目录结构说明

```
mockmirror/
├── server.js              服务入口
├── lib/                   领域层（面试/Agent/题库/RAG/ASR/存储）
├── public/                前端页面与脚本
├── mcp/                   MCP 服务器
├── data/                  题库、知识库、运行数据（配置与备份不入库）
├── scripts/               安装与工具脚本
├── test/                  自动化测试
├── python-agent/          可选的 Python Agent 服务
├── docs/                  文档（含毕业设计系列）
├── 启动面试.bat            Windows 一键启动
└── start.sh               macOS/Linux 一键启动
```

## 8 卸载与清理

1. 关闭服务窗口（或在任务管理器结束 node 进程）；
2. 删除项目目录即可，无注册表与系统级残留；
3. 若需清除个人面试数据，删除 `data/db.json` 与 `data/backups/`。
