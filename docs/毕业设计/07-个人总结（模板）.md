### 一、项目概述

「面镜 MockMirror」是一套面向高校学生的 AI 模拟面试与能力提升软件，以全语音交互还原真实面试场景，由具备工具调用能力的面试官 Agent 自主主持追问与换题，面试结束后由评估官与陪练官 Agent 联合产出逐题复盘与提升计划，并通过 MCP 协议对外开放面试能力。

系统采用 B/S 架构，服务端基于 Node.js 内置模块实现（零第三方依赖），前端为原生 HTML/CSS/JS，语音识别集成本地离线引擎，数据以 JSON 文件原子化存储。项目共 3 个岗位、159 道题目、27 个 REST 接口与 9 个 MCP 工具。

### 二、本人承担的主要工作

> 示例（语音链路负责人，请按自己角色改写）：

1. **本地离线语音识别引擎集成**（lib/asr.js）。引入 sherpa-onnx 流式 zipformer 双语模型，完成引擎懒加载、会话级流隔离与资源回收，实测识别实时率 RTF 达到 0.041。
2. **浏览器端音频采集与分片上传**（public/js/localasr.js）。以 16kHz 采样、160 毫秒分片的方式把 PCM 音频编码后实时上传，实现边说边识别。
3. **自动提交判定**。结合服务端端点检测（静音 0.8 秒）与 60 余条结束词字典（仅判定句尾 14 字，避免句中"不知道"误判），实现"说完就自动提交"，全程无需键盘。
4. **打断与设备切换**。实现空格键打断（区分"打断面试官"与"提交作答"两种语义），以及会前检测与会中热切换麦克风。
5. **跨平台安装器**（scripts/setup-asr.js）。自动识别操作系统与架构下载对应运行时，提供镜像兜底与 `--skip` 跳过选项。

> - **分析**：Chrome 内置语音识别依赖境外服务，国内网络环境下请求被阻断，这是外部依赖问题，重试无意义。

> - **效果**：断网条件下仍可完成面试，识别实时率 RTF 0.041，首字延迟约 320 毫秒。
